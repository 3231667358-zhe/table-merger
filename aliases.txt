# ============================================================================
# 别名表（默认空模板 —— 一条都没启用）
# ============================================================================
#
# 这个文件是「显式配置」：只有你在这里亲手写下的对应关系才会生效。
# 工具不会去猜「名字」和「姓名」是不是同一个字段 —— 不写，就是两个不同的列。
#
# 这个文件叫 aliases.txt，和 merge.py 放在一起，工具默认自动加载它。
# 想用别的文件：python3 merge.py 数据目录 --aliases 我的别名表.txt
# 想完全不用：  python3 merge.py 数据目录 --no-aliases
#
# ---------------------------------------------------------------------------
# 格式：每行一条
#     标准名 = 别名1, 别名2, 别名3
#
#   - 以 # 开头的是注释，空行忽略
#   - 分隔符可以用英文逗号、中文逗号（，）、顿号（、），随便混用
#   - 等号左边的「标准名」本身也算自己的别名，不用再写一遍
#   - 同一个别名不能指到两个不同的标准名（工具会报错，不会替你猜）
#
# 含义：等号左边的名字 = 输出表里显示的名字；
#       右边的名字 = 各个源文件里可能出现的写法，都会被归到左边这个标准名。
#
# 例：写了 "姓名 = 名字, 员工姓名" 之后
#     a.csv 里的「姓名」列、b.csv 里的「名字」列、c.xlsx 里的「员工姓名」列，
#     在输出里合并成同一列，表头显示「姓名」。
#
# ---------------------------------------------------------------------------
# 重要限制：同一张表里不允许两列归到同一个列名
#
#   如果一个文件里同时有「姓名」和「名字」两列，又写了上面那条别名，
#   同一行的两个值就要抢同一个输出格子，必然丢数据。
#   这种情况下工具会直接报错停机并指出是哪两列撞了，不会自动改名、不会静默合并、
#   也不会丢掉其中一列，而且不会产出任何文件。
#
#   （跨文件归到同一列不算撞车：那是不同行，不会互相覆盖，也正是别名表的用途。）
#
# ---------------------------------------------------------------------------
# 下面全是注释掉的示例，需要就照着改成你自己的字段。
# 覆盖：examples/aliases_demo.txt 是配合 examples/input 演示数据用的别名表，
#       用 --aliases examples/aliases_demo.txt 显式指定即可。
# ---------------------------------------------------------------------------
